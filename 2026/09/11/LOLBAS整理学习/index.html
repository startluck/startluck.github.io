LOLBAS 网站介绍（https://lolbas‑project.github.io/）

LOLBAS = Living Off The Land Binaries, Scripts and Libraries，中文常译为：就地取材二进制、脚本与库文件库。

“Living Off The Land（LotL，就地取材攻击）”：攻击者不落地恶意程序，滥用 Windows 系统自带、微软签名的合法程序完成攻击行为，规避杀毒软件检测。

该项目是开源社区维护的 Windows 安全知识库，
记录 Windows 下微软签名的二进制、脚本、库文件被滥用的攻击手法，收录的不是软件漏洞，而是合法程序的非预期恶意用法。
